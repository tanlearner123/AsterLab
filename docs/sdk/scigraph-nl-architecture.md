# ADR: AsterLab 文件级全局科学语义网络（`SciGraph`）与端侧轻模型协同架构

- **日期**：2026-11-22
- **状态**：已确认并落地（Phase 1–3 演进基线）
- **关联文档**：[`docs/sdk/nl-extraction-schema.md`](nl-extraction-schema.md)、[`docs/sdk/nl-router-upgrade.md`](nl-router-upgrade.md)、[`docs/asterdoc-contract.md`](../asterdoc-contract.md)

---

## 1. 背景与实测驱动

在 5 套真实全流程湿实验协议（HUVEC 成管、RT-qPCR、Western Blot、CCK-8 IC50、免疫荧光共聚焦，共 63 行真实实验文本）的压力测试中，我们将 22.87 MB 离线 INT8 ONNX 模型与云端教师 `jev-latest` 逐分区对比，发现了四类底层根因：

1. **文档结构区未门禁**：标题行（`#@` / `##@`）与静态设计摘要行（`- **研究体系**：...`）被裸送入模型，贡献了绝大部分误报；
2. **小模型与代码的职责混杂**：用脆弱关键词正则判定“过去式复盘”或“是否多动作”风险高，而把大段全局上下文塞给 24M 双塔编码器又会稀释 `[CLS]` 注意力并拉高延迟；
3. **跨组件数据血缘未统一**：例如 `plate` 中第 4 列标记了 `role: blank`（PBS 防蒸发空白孔），但计算器 `@plate.wells` 仍按 12 孔算预混液、采图网格也未统一消费有效实验孔数；
4. **不确定公式时的越界猜测**：当句子包含明确科学变量但数学公式不唯一时，强行猜一个公式容易算错，应先抽出科学变量填好，公式留给科研人员快速选定。

## 2. 核心架构决策（6 条已确认原则）

### 决策 1：厚代码科学网络（`SciGraph`）+ 轻模型语义传感器（`nlengine`）

- **代码（纯 Go，`< 0.5 ms` 编译 / `~5 µs` 查询）**承担所有确定性、状态化与网络化职责：文档 AST 分区、全局科学符号表、组件间动态联动同步、子句分发与结果汇总、确定性算术与 `specValidator` 校验。
- **23 MB 端侧 ONNX 模型（纯 Go `2.15 ms`）**只承担最擅长的轻量化语义传感职责：单子句意图路由、`p_pos` 连续可操作概率守门、`is_multi` 多操作语义判别，以及未来的轻量相似度排序，**绝不过载**。

### 决策 2：宿主确定性结构门禁（哪些内容允许语义转组件）

由 `SciGraph.ContextAt(offset)` 按文档 AST 确定性判定区域（`Zone`），绝不靠模型猜：

| `Zone` 区域 | 是否开放 `Alt + Hover` 语义转组件 | 允许目标范围 |
|---|---|---|
| `step_body`（`#@` / `##@` 步骤内的操作描述句） | **✅ 开放** | 全部步骤工具（`timer` / `calculator` / `attachment` 等） |
| `design_plan`（设计章节中的普通规划句） | **✅ 有限开放** | 仅 `plate_group` 与 `calculator` |
| `heading`（`#` / `##` / `#@` / `##@` 标题行） | **❌ 禁止** | — |
| `metadata`（Frontmatter、`**研究体系**：` / `**实验目的**：` 等属性摘要行） | **❌ 禁止** | — |
| `materials` / `review`（耗材清单、复盘、讨论、数据分析章节） | **❌ 禁止** | — |

### 决策 3：`SciGraph` 分层上下文注入（极速 + 零污染）

`SciGraph` 直接从当前 `.asterml` 文档实时编译并按文档内容哈希缓存（编译 `< 0.5 ms`，查询 `~5 µs`），按阅读顺序只收集当前行之上的动态语义（`offset <= 当前行`），并按消费者分层注入：

| 消费者 | 注入粒度 | 原因 |
|---|---|---|
| **组件间实时同步 & Go 参数提取器** | **完整 `SciGraph`（5 µs 全量直读）** | 零污染、零延迟；`plate` 改空白孔 → 计算器 `@plate.sample_wells`、采图网格槽位、悬停缺参时的上文试剂（如 `VEGF 100 ug/mL`）与孔板引用同步生效 |
| **23 MB 端侧 ONNX 编码器** | **极简微上下文：`[步骤名] + 当前句`**（短/指代句才带极短上句，总量 `< 60 token`） | 防止整份 `SciGraph` 的孔板/试剂词淹没 4 层小模型的注意力导致强负样本误报，保持 `2.5–3.5 ms` 延迟 |
| **按需云端大模型 / Jev 副驾驶** | **`SciGraph.CompactSummary(offset)`（< 150 token）** | 大模型擅长消费压缩版全局语义摘要处理复杂跨句推理 |

### 决策 4：放弃脆弱关键词正则，由模型自身主控“整句守门 + 多动作分流”

1. **整句守门（零关键词正则）**：先对整句跑 1 次 ONNX（2.15 ms），若模型自身的连续概率 `p_pos < 0.25`（过去式复盘、文献引用、条件跳过等语义上天然落在此区间），直接静音、绝不拆句；
2. **多操作判别与分路（0 额外首遍延迟）**：复用同一次编码得到的 512 维向量 `v` 做 2 维点积判别 `single vs multi`（在 `v1.3` 蒸馏训练中纳入 `jev-latest` 标注的单/多操作对）；只有模型判定 `multi` 时，代码才按自然标点拆为 2–3 个子句各过一次 2 ms ONNX 并去重汇总成多动作预览卡。

### 决策 5：不确定公式时的人机协同（先填科学语义，公式交给人选）

- 底层坚持唯一通用组件 `calculator@1`（`mode: formula` + `rows[]`），绝不新增实验专用计算器类型；
- 提供 8 套高频通用湿实验公式模板（`C₁V₁=C₂V₂ 稀释`、`比例稀释 1:N`、`连续倍比稀释`、`% w/v 称量`、`摩尔称量`、`孔板预混`、`细胞接种`、`RCF↔RPM 离心力` + `自定义 LaTeX`）；
- 当自然语言句子有明确计算意图但具体公式不确定时，先将识别出的科学变量（试剂名、浓度、体积、孔数、上文继承值）填入输入变量行，公式区留给用户在公式库或 LaTeX 栏一秒选定。

### 决策 6：组件间动态语义同步以 `SciGraph` 为唯一真值源

- `plate` 中标记 `role: blank` 的孔位与有效实验孔自动分离：`TotalWells`、`SampleWells`（排除 `blank`）、`BlankWells`；
- 计算器支持 `@plate.sample_wells`（默认用于预混液与 `+ 引入孔板实验孔数`）与 `@plate.wells`（保留向后兼容），以及 `@group.<id>.wells`；
- 采图网格 `attachment` 与 `Alt + Hover` 缺参兜底共享同一份 `SciGraph.ActivePlate` 与 `UpstreamReagents`。

## 决策 7：严格单文档动态加载边界与方向 A（实验内深度闭环）

为防止跨文件隐式继承带来的语义污染与架构失控，`SciGraph` **严格限定在当前打开的单篇 `.asterml` 文档内实时编译**；跨文档关联一律保持显式可控的 `![[...]]` / `[[...]]` 嵌入，不做隐式全局抓取。

在此单文档边界内，落地**方向 A（单文档科学网络深度闭环）**：

1. **计算器级联响应式网络 (`@calc.<module_id>.<row_key>`)**：
   - `SciGraph` 按文档拓扑顺序（带防环保护）求值上游 `calculator@1` 的输出行并注册为 `calc_<id>_<key>` 变量；
   - 下游计算器可直接引用 `@calc.<id>.<key>`（支持输入值绑定或 LaTeX 公式内联），修改上游任意输入实时级联重算下游；UI 提供一键 `+ 引用上游计算 ▾` 菜单。
2. **文档内纯文本试剂事实轻量入图（结构化模块优先）**：
   - `SciGraph` 在单文档内按行序轻量提取纯文本试剂定义（如 `DAPI 储液 1 mg/mL`、`Doxorubicin 母液 10 mM (MW=543.5)`），标记 `SourceModuleID: "prose"`；
   - 若上游已有结构化 `calculator@1` / `param_table@1` 同名试剂，结构化事实始终覆盖纯文本事实，兼顾零漏检与零脏数据。
3. **运行态时间锚点 (`{#t0}`) 自动唤醒下游时间窗**：
   - 当锚定步骤内的计时器启动/完成（含 `started_at` / `completed_at`）或用户点击「标记此刻为 t0」时，同文档内所有绑定 `anchor: t0` 的下游 `timer@1` (`mode: window`) 自动换算真实墙钟目标时刻与剩余倒计时，实现全流程时间网络联动。
4. **低置信分流抑噪 (`minTopConf = 0.35`)**：
   - 当 23 MB 本地 ONNX 传感器出现多类概率分散（`bestProb < 0.35` 且 `p_pos < 0.85`）时自动降噪为 `none`，抑制长混合描述句的偶发抖动。

## 决策 8：物理护栏、确定性孔板排版引擎、`SciUnit` 消费闭环与文档心智分工

1. **继承物理护栏 (`C₁ > C₂`) 与多板具名引用**：
   - 纯文本试剂收割严格限定母液关键词（`母液/储液/原液/stock/浓缩液/MW`），屏蔽 `工作浓度/终浓度`；稀释继承必须满足同量纲 **`C₁ > C₂`**，彻底杜绝工作浓度覆盖母液导致的负补液量。
   - 多孔板文档新增具名绑定 **`@plate.<id>.sample_wells`** 与全局汇总 **`@plate.all_sample_wells`**（单板文档仍兼容 `@plate.sample_wells`）。
2. **确定性孔板排版引擎 (`plate_layout.go`)**：
   - 语义模型只提取逻辑规格（板型、分组、复孔数、是否显式要求边缘防蒸发），**物理坐标 100% 由确定性算法顺排生成**，不做自动区组随机化。
   - 孔板右键菜单提供「**按行顺排（横排）** / **按列顺排（竖排 · 8 道排枪）** / **切换外周留空防蒸发（PBS）**」；默认不强制外周留空，开启外周留空且单板容量不足时绝不静默截断（右键切换明确提示溢出孔数，`Alt + 悬停` 新建时自动拆分为多块板）。
3. **统一实验单位 (`SciUnit`) 全链消费**：
   - `SciGraph` 自动构建每孔一行的 `Units / UnitByPlateWell`，孔板标记 `excluded_wells` 异常孔后全链实时剔除：计算器 `@plate.sample_wells`/`@group.<id>.wells` 自动减孔、采图网格自动跳过、数据表矩阵粘贴自动归组并跳过异常孔、`SummarizeWellReadings` 自动做 `Blank` 本底扣除与 `Mean ± SD` 汇总。
4. **文档心智分工（顶部蓝图 → 步骤就地工具）**：
   - 顶部「实验设计」只放跨步共享的静态对象（`group_table`、`plate`、试剂母液清单）；具体动作工具（`calculator`、`timer`、`attachment`、`data_table`）一律就地放进对应实验步骤中，由 `SciGraph` 后台无缝串联。
