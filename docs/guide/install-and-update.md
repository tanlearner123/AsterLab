# 下载、安装与更新

## 1. 下载与安装

请前往 GitHub Releases 页面下载适合你系统的安装包：

| 系统 | 推荐下载 | 安装方式 |
|---|---|---|
| **Windows (64 位)** | `AsterLab-MyGo-<版本>-win-x64-setup.exe`（安装版）<br/>或 `AsterLab-MyGo-<版本>-win-x64.zip`（免安装便携版） | 双击安装程序按提示完成（无需管理员权限）。安装后会自动关联实验文档双击打开，并在桌面创建快捷方式。 |
| **macOS** | `.dmg` 安装镜像 | 打开后将 AsterLab 拖入「应用程序」文件夹即可。 |
| **Linux** | `.deb` 或 `.tar.gz` | 安装 `.deb` 或解压后直接运行。 |

> [!TIP]
> **关于安装时的「离线智能识别组件」**：Windows 安装包在安装向导中提供可选勾选的「离线智能识别组件（约 23 MB）」。勾选后，无需联网即可使用更精准的「文字一键变组件」功能；即使不勾选，主程序全部实验记录、孔板、计算器与统计功能也能正常使用。

> [!NOTE]
> 测试版阶段暂未购买商业代码签名证书，Windows 首次打开若弹出 SmartScreen 提示，可点击「更多信息 → 仍要运行」。

---

## 2. 应用内检查更新与升级

- **自动提醒**：当有新版本发布时，软件底部状态栏右侧会出现「新版本」提示，点击即可前往更新。
- **手动检查**：点击左下角齿轮打开「设置 → 关于与更新」，点击「检查更新」即可一键下载并重启完成升级。
- **覆盖安装也安全**：你也可以直接下载新版安装程序覆盖安装，软件会自动关闭旧进程并平滑替换，不会影响任何实验数据。

---

## 3. 你的实验数据保存在哪里？

- **软件与数据完全分离**：升级、重装甚至卸载 AsterLab，**永远不会删除**你的实验库文件夹、实验记录和实验照片。
- **随时打开文件夹查看**：在左侧文件树右键任意实验，选择「在文件管理器中显示」，就能直接看到你电脑上的真实文件。
- **换电脑或备份**：直接把整个实验库文件夹复制到移动硬盘、坚果云、OneDrive 或 iCloud 即可完整带走所有实验记录与图片。
