# 书写实验笔记、快捷输入与快捷键

你完全可以**全程用鼠标点选**完成所有操作；如果你习惯用键盘快速录入，AsterLab 也支持像 Obsidian / Notion 一样的轻量快捷写法，下面用真实例子一一演示。

---

## 1. 插入步骤与组件（两种方式任选）

- **鼠标点选**：
  - 点击画布顶部悬浮条的 **`+`** 按钮；
  - 或把鼠标移到任意一行的左侧边缘，点击浮现的 **`+`** 图标。
- **键盘 `/` 命令**：
  - 在空白行输入 **`/`**，立刻弹出组件菜单，直接输入中文或英文筛选（如输入 `/孔板`、`/计算`、`/计时`、`/表格`），按回车插入。

---

## 2. 常用快捷输入示例（可选）

下面这些写法全部是**可选的**——不会也没关系，点菜单都能做到：

| 你打出的文字 | 呈现效果 | 适用场景 |
|---|---|---|
| `#@ 细胞接种与铺胶` | 带编号和左侧纵线的 **主步骤** | 划分大的实验阶段 |
| `##@ 配制工作液` | 缩进在主步骤里的 **子步骤** | 细化某一步里的具体操作 |
| `- [ ] 检查培养箱 CO₂ 浓度` | 可直接点击打勾的 **待办核对项** | 实验室防漏步清单 |
| `**全程避光操作**` | **全程避光操作** | 突出关键注意事项 |
| `## 实验目的` | 二级章节标题 | 分隔实验设计与结果讨论 |
| `[[2026-11-18 预实验]]` | 可点击跳转的 **双向实验链接** | 关联上一次预实验或通用 SOP |

> [!TIP]
> 在任意步骤标题后加上 `{#t0}`（例如 `#@ 加药处理 {#t0}`），就能把这个步骤标记为时间起点，后续 6h / 12h / 24h 的时间窗提醒都会以它为基准自动推算时刻。

---

## 3. 全部快捷键速查表

| 快捷键 | 做什么 |
|---|---|
| `Ctrl + K` | **快速跳转**：输入实验名瞬间切换，或搜索任意功能 |
| `Ctrl + Shift + F` | **全库全文搜索**：在所有历史实验里搜试剂、批号或现象 |
| `Ctrl + E` | 在 **「编辑」** 与 **「实验（防误触）」** 模式间一键切换 |
| `Ctrl + F` | 在当前实验文档内查找文字 |
| `Alt + 悬停` / `Alt + Enter` | 识别当前操作句，预览并一键转为计算器、计时器或孔板 |
| `Ctrl + V` | 在数据表/孔板矩阵中直接粘贴 Excel 或酶标仪多行数据；在正文中直接粘贴截图 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `Ctrl + \` | 展开或收起左侧文件栏 |
| `F2` / `Delete` | 在左侧文件树重命名 / 删除选中的实验或文件夹 |
