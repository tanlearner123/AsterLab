# 欢迎使用 AsterLab

AsterLab 是一款专为生物与湿实验科研工作者打造的**本地实验记录与设计工作台**。

它把平时散落在 **Word 方案、Excel 孔板图、计算器、手机计时器和纸质实验记录本** 里的内容，收拢到同一份清晰的本地实验文档里——你不需要懂编程或任何复杂语法，点选、拖拽、右键和复制粘贴就能完成从实验设计到结果汇总的全过程。

## 为什么你会喜欢它

- **文件完全留在你自己的电脑里**：所有实验文档与显微照片都以普通文件夹形式保存在本地，不绑架数据、断网也能流畅使用，随时可以复制、备份或用网盘同步。
- **一份文档贯穿全流程**：顶部放实验分组和孔板图，中间按步骤写操作并放配液计算器与计时器，底部直接贴酶标仪读数自动算均值和扣空白。
- **改一处，全篇联动**：实验过程中在孔板上标记了某个污染/气泡异常孔，配液计算器的有效孔数、采图槽位和底部读数统计会自动同步排除它，不再靠人工来回改表。
- **写平时的话，就能变出工具**：在步骤里写一句“将 VEGF 稀释至 50 ng/mL，终体积 5 mL”或“37°C 孵育 30 min”，点一下行尾微亮的 `✦`（或按住 `Alt` 悬停），软件会自动帮你算好并一键生成可交互组件。
- **进实验室一键开启防误触**：切到「实验」模式后，步骤原文与孔板布局自动锁定，防止戴手套误删文字，只保留计时、勾待办、录读数、标异常孔和传照片。
