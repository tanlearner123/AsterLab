# 台面执行模式、计时器、照片关联与读数统计

## 1. 走进实验室：切换到「实验」模式

在办公桌写完方案后，带着电脑或平板走到实验台，点击文档右上角的 **「实验」**（或按 `Ctrl + E`）：
- **防误触锁定**：步骤正文、分组定义和孔板布局全部锁住，戴着手套误碰键盘或滑屏也不会改乱原方案；
- **依然开放台面刚需操作**：勾选待办清单、启停计时器、标记异常孔、直接往数据表填数/贴数、给孔位关联显微照片，以及在空白补记区记录突发偏离。

需要修改方案设计时，再点右上角 **「编辑」** 即可随时切回。

---

## 2. 计时器与全流程时间起点（`t0`）

计时器支持 4 种模式，满足几乎所有湿实验节拍：
- **倒计时**：常规孵育、离心、染色、固定；
- **秒表留痕**：记录真实耗时（例如“蓝光照射至水凝胶完全固化，记录实际秒数”）；
- **交替循环**：如“80°C 水浴 5 min ↔ 冰上 10 min，共 3 轮”，自动计算总耗时；
- **时间窗提醒（联动 `t0`）**：
  1. 在关键起点步骤（如「接种完成」或「加药」）标注 `{#t0}`，并在下方时间窗提醒中选择起点 `t0`；
  2. 现场完成该步后点击 **「标记此刻为 t0」**，下游所有 `t0 + 2h`、`t0 + 6h`、`t0 + 24h` 采图或换液提醒会自动换算成精确墙钟时刻并开始倒计时；
  3. 如果打点早了，点击时间条上的 **「重设」** 即可清零重打。

所有运行中的计时器都会汇总在右侧抽屉的「速算计时」与底部状态栏，切去查别的实验也不会错过响铃。

## 3. 显微照片与结果图关联孔位

1. **插入照片**：直接把电脑里的 PNG / JPG 照片拖进文档，或在正文按 `Ctrl+V` 粘贴截图；
2. **关联到孔位**：悬停图片卡片点击 **「关联」**，依次选择：
   - 对应的孔板（或步骤/组别）；
   - 孔位（如 `A1` 或 `A1,A2`）、时间点（如 `6h`）、视野编号（如 `1`）；
   - 照片类型（下拉选择：`观察图` / `原始数据` / `参考图`）。
3. **双向反查**：以后在孔板上点选 `A1` 孔，下方立刻会列出这个孔拍过的所有历史照片；点击任意照片即可放大查看细节。

## 4. 从 Excel / 酶标仪粘贴读数与自动统计

### 4.1 像用 Prism 一样直接粘贴
- **列表视图**：点进数据记录表的任意单元格，直接按 **`Ctrl + V`**，即可把 Excel 里的多行多列数据完整粘入；
- **孔板矩阵视图**：点数据表右上角 **`···` → 切换为孔板矩阵视图**，即可按 12/24/96 孔板排布核对，点进 `A1` 直接 `Ctrl + V` 粘贴酶标仪导出的 8×12 矩阵（自动识别行列头，自动跳过异常孔）。

### 4.2 自动读数汇总
只要数据表关联了孔板或分组，文档底部会自动出现 **「读数自动汇总」** 卡片：
- 自动剔除孔板上标过的 **异常孔**（明确显示 `已剔除 M 异常孔`）；
- 自动识别 **空白孔** 计算本底均值，并给出 **扣空白均值**；
- 清晰区分 **技术复孔数** 与 **独立样本数 `n`**；
- 对 CCK-8 / OD450 活力表自动算相对活力百分比，对 RT-qPCR 含内参基因的 Ct 表自动算 `ΔΔCq` 与相对表达倍数，其他定量表给出清晰的均值 ± 标准差。
